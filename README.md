# 📋 Todo List JS

Projeto desenvolvido para praticar JavaScript.

## Funcionalidades

- Adicionar tarefas
- Excluir tarefas
- Marcar como concluídas
- Adicionar tarefa com Enter
- Persistência com Local Storage

## Tecnologias

- HTML
- CSS
- JavaScript

## Aprendizados

- Manipulação do DOM
- Eventos
- Arrays
- Local Storage
